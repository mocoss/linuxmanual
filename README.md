## 🚀 快速开始

### 在线浏览

访问网站：https://mocoss.github.io/linuxmanual/

### 本地运行

```bash
# 克隆项目
git clone https://github.com/mocoss/linuxmanual.git
cd linuxnotes

# 安装依赖
npm install

# 本地预览
npx quartz build --serve
```

浏览器打开 `http://localhost:8080`

### 使用 Obsidian 编辑

1. 下载安装 [Obsidian](https://obsidian.md/)
2. 打开仓库文件夹作为 Vault
3. 直接编辑 `content/` 目录下的 Markdown 文件
